# SEO Brief Pattern: Fallback Templates & Efficiency Safeguards

This file contains manual alternatives and templates used when API limits are reached or for maximum efficiency.

## Semantic Keyword Templates

### E-commerce Keywords
**Primary:** "best [product] for [audience]"
**Semantic variations:**
- top [product] [year]
- [audience] [product] guide
- [product] comparison
- affordable [product] for [audience]
- [product] reviews

### Software/SaaS Keywords
**Primary:** "[software type] for [business size]"
**Semantic variations:**
- [software type] comparison
- best [software type] tools
- [software type] pricing
- [software type] features
- [business size] [software type] solutions

### Service-Based Keywords
**Primary:** "[service] in [location]" or "[service] for [audience]"
**Semantic variations:**
- professional [service]
- [service] cost
- [service] benefits
- how to choose [service]
- [service] consultation

## Competitor Analysis Templates

### Standard Competitor Framework
When API data unavailable, use this manual analysis:

**Top 3 Competitor Assessment:**
1. **Competitor 1 (Position #1)**
   - Content Type: [Guide/Listicle/Comparison/Review]
   - Estimated Word Count: [1500-2500/2500-4000/4000+]
   - Main Sections: [Introduction, Features, Pricing, Conclusion]
   - Unique Angle: [Price focus/Feature depth/User experience]

2. **Competitor 2 (Position #2)**
   - Content Gap: [Missing pricing details/Limited examples/No FAQs]
   - Opportunity: [Add pricing table/Include case studies/FAQ section]

3. **Competitor 3 (Position #3)**
   - Weakness: [Outdated info/Poor UX/Limited depth]
   - Positioning: [Fresh data/Better design/More comprehensive]

### Industry-Specific Templates

#### Technology/Software
- **Standard Sections:** Features, Pricing, Integrations, Security, Support
- **Common Gaps:** Implementation timeline, ROI calculator, migration guide
- **Opportunity Areas:** Video demos, free trials, comparison charts

#### Healthcare/Medical
- **Standard Sections:** Benefits, Process, Cost, Insurance, Qualifications
- **Common Gaps:** Patient testimonials, before/after, success rates
- **Opportunity Areas:** FAQ, virtual consultations, insurance coverage

#### Finance/Business
- **Standard Sections:** Services, Pricing, Process, Experience, Results
- **Common Gaps:** Case studies, ROI data, implementation timeline
- **Opportunity Areas:** Calculator tools, consultation booking, testimonials

## Content Structure Templates

### Comparison/Best-of Articles
```
H1: Best [Product/Service] for [Audience] ([Year])
H2: What is [Product/Service]?
H2: How We Chose the Best [Product/Service]
H2: Top [Number] [Product/Service] Options
  H3: [Product 1] - Best Overall
  H3: [Product 2] - Best for [Specific Use]
  H3: [Product 3] - Most Affordable
H2: [Product/Service] Buying Guide
H2: Frequently Asked Questions
H2: Final Thoughts
```

### How-to/Guide Articles

## Linking Strategy Templates

### Internal Linking Opportunities
**Anchor Text Patterns:**
- "Learn more about [topic]" → Related guide/tutorial
- "Check out our [product/service]" → Service pages
- "Read our complete guide to [topic]" → Comprehensive articles
- "See also: [related topic]" → Related blog posts

**Strategic Internal Links:**
1. **Topic Clusters:** Link to pillar content and related subtopics
2. **User Journey:** Link to next logical step in customer journey
3. **Resource Pages:** Link to tools, templates, or calculators
4. **Case Studies:** Link to relevant success stories

### External Authority Sources
**Technology/Software:**
- TechCrunch, Wired, The Verge (industry news)
- Gartner, Forrester (research reports)
- Stack Overflow, GitHub (technical resources)

**Business/Finance:**
- Harvard Business Review, McKinsey (strategy)
- Forbes, Bloomberg (business news)
- SBA.gov, IRS.gov (official resources)

**Healthcare:**
- Mayo Clinic, WebMD (medical information)
- CDC, NIH (official health data)
- Medical journals (peer-reviewed research)

## Efficiency Triggers

### Use Manual Templates When:
- Monthly API calls > 200 (80% of budget)
- Keyword is informational/low-competition
- Similar brief created recently (reuse research)
- Time-sensitive content needed quickly

### Use API Calls When:
- Commercial/high-value keywords
- Competitive landscape unknown
- New industry/topic area
- Client requires comprehensive research

### Smart Batching Opportunities:
- Group similar keywords in single session
- Research competitor once, apply to multiple briefs
- Batch seasonal content research
- Combine related topic clusters
