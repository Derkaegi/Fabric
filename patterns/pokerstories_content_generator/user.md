# PokerStories Content Generator

Please provide your content request using one of these formats:

## Character Profile Format:
```
Character Profile:
- Name: [Full name and nickname]
- Era: [Years active 1998-2011]
- Role: [Player/Entrepreneur/Platform owner/etc.]
- Key Achievement: [What they're known for]
- Personal Stakes: [What they risked/gained]
- Cultural Impact: [How they influenced the scene]
```

## Platform Profile Format:
```
Platform Profile:
- Name: [Site/Platform name]
- Founded: [Year, key founders]
- Peak Era: [Years of dominance]
- Innovation: [What made them unique]
- Community Impact: [Cultural significance]
- Downfall/Transition: [How it ended/evolved]
```

## Era Snapshot Format:
```
Era Snapshot:

- Key Events: [Major happenings]
- Cultural Mood: [What the scene felt like]
- Technology: [Platform innovations]

```

## Behind-the-Scenes Format:
```

## Memory Collection Format:
```
Memory Collection:
